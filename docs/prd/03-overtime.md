# 03. 연장근로(오버타임) 계산

[← PRD 개요](README.md) · 기본급·주휴수당은 [02-pay.md](02-pay.md)

## 목표

약속한 시간보다 더 일한 시간을 골라내고, 가산수당(통상임금의 50%)을 더한다.

## 법 기준

| 대상 | 기준 | 근거 |
|---|---|---|
| 단시간근로자 (1주 소정근로시간 40시간 미만) | **소정근로시간을 넘긴 시간**에 통상임금의 100분의 50 이상 가산. 초과근로는 1주 12시간까지 | 기간제 및 단시간근로자 보호 등에 관한 법률 제6조 |
| 통상근로자 | 1일 8시간·1주 40시간을 넘긴 연장근로에 100분의 50 이상 가산 | 근로기준법 제50조, 제56조 |
| 상시 4명 이하 사업장 | 위 가산 의무가 적용되지 않는다 | 근로기준법 제11조·시행령 별표 1, 기간제법 제3조 — **조문 원문은 대조하지 못했다 (확인 불가)** |

- [찾기쉬운 생활법령정보 — 단시간근로자의 특별보호](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1347&ccfNo=3&cciNo=2&cnpClsNo=2)
- [국가법령정보센터 — 기간제 및 단시간근로자 보호 등에 관한 법률](https://www.law.go.kr/LSW/lsInfoP.do?urlMode=lsInfoP&lsId=010356)

소정근로시간은 1일 8시간·1주 40시간을 넘을 수 없으므로, 두 기준은 "소정근로시간 초과분" 하나로 합쳐 계산한다.

## 계산식

설정의 **1일 소정근로시간 = 1주 소정근로시간 ÷ 1주 소정근로일수** (예: 20 ÷ 5 = 4시간).

한 주에 대해:

```
일별 초과 합계 = Σ max(0, 그날 근무시간 − 1일 소정근로시간)
주간 초과      = max(0, 그 주 근무시간 − 1주 소정근로시간)
연장근로시간   = max(일별 초과 합계, 주간 초과)       # 같은 시간을 두 번 세지 않는다
가산수당       = 연장근로시간 × 시급 × 0.5            # 5인 이상 사업장일 때만
```

- 연장근로 시간 자체의 임금(1배)은 이미 [기본급](02-pay.md)에 들어 있다. 여기서는 **가산분 50%만** 더한다.
- "상시 5인 이상 사업장" 설정이 꺼져 있으면 연장근로시간은 표시하되 가산수당은 0원이다.
- 1주 12시간 초과근로 한도를 넘기면 급여 화면에 경고를 띄운다. 계산은 그대로 한다.

## MVP 에서 빠진 것

- 야간근로(22시~06시) 가산, 휴일근로 가산
- 휴게시간 차감

## 수용 기준

| ID | 기준 |
|---|---|
| O-1 | 1일 4시간 계약, 하루 6시간 근무(그 주 다른 근무 없음) → 연장 2시간, 가산 10,320원 (시급 10,320원) |
| O-2 | 1주 20시간 계약, 주 5일 각 5시간 근무 → 일별 초과 5시간, 주간 초과 5시간 → 연장 5시간 |
| O-3 | 5인 미만으로 설정 → 가산 0원 |
| O-4 | 연장 12시간 초과 → 한도 경고 표시 |

O-1~O-3 은 `web/src/lib/pay.test.mjs` 에 테스트로 있다.
