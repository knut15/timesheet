# 13. 근무 시간표 — 요일·출퇴근 시각, 날짜별 변경

[← PRD 개요](README.md) · 급여 조건은 [07-admin.md](07-admin.md) · 주휴 기준은 [02-pay.md](02-pay.md)

## 목표

사장님(마스터)이 멤버마다 **근무 요일과 출근·퇴근 시각**을 정한다. 대타나 사정으로 하루만 달라지는 날은 **그 날짜만** 바꾼다.
(2026-09-25 사용자 결정: "출퇴근 시간을 선택할 수 있게", "대타 혹은 변경이 있을 수 있으니 요일과 시간을 변경할 수 있는 옵션")

## 결정

| 항목 | 결정 |
|---|---|
| 형태 | 기본 시간표 = 근무 요일(월~일 중 1개 이상) + 출근 시각 하나 + 퇴근 시각 하나. 요일마다 다른 시각은 두지 않는다 |
| 시각 | 30분 단위 선택. 퇴근 > 출근, 자정을 넘는 근무는 두지 않는다 |
| 주 시간·주 일수 | **시간표에서 계산한다.** 주 일수 = 요일 수, 주 시간 = 요일 수 × (퇴근 − 출근). 직접 입력칸은 없앤다. 합이 52시간을 넘으면 저장하지 않는다 |
| 휴게시간 | 빼지 않는다 — 실제 근무 기록 계산(pay.ts)도 휴게시간을 빼지 않는 것과 맞춘다 |
| 날짜별 변경 | 기본 시간표는 그대로 두고 **그날 하루만** 예외: `쉼` 또는 `근무 HH:MM~HH:MM`(원래 쉬는 날 추가 근무, 시각 변경 모두). 한 멤버의 한 날짜에 하나 — 다시 등록하면 덮어쓴다 |
| 날짜별 변경이 급여에 주는 영향 | 없음. 주휴 판단의 소정근로시간·일수는 기본 시간표 값이다. 실제 급여는 지금처럼 근무 기록으로 계산한다 |
| 누가 | 사장님만 정하고 바꾼다. 멤버는 내 정보 탭에서 보기만 한다 |
| 시간표가 없는 멤버 | 이 기능 전부터 있던 멤버는 시간표가 비어 있고 옛 주 시간·주 일수를 그대로 쓴다. 조건 수정에서 시간표를 정하면 그때부터 계산값으로 바뀐다 |
| 출근 버튼 | 시간표와 무관 — 퇴근 뒤 막힌 버튼은 지금처럼 다음 날 0시에 켜진다 ([12](12-member-today.md) T-7) |

## 화면

| 누가 | 어디 | 무엇 |
|---|---|---|
| 마스터 | 멤버 탭 → 멤버 카드 "조건 수정" | 시급(천 단위 쉼표), 근무 요일 버튼 7개, 출근·퇴근 선택, 계산된 `주 N시간 · N일` 미리보기 |
| 마스터 | 멤버 카드 "날짜별 변경" | 오늘 이후 예외 목록(날짜·쉼/시각·삭제) + 추가(날짜, 쉼/근무, 시각) |
| 멤버 | 내 정보 → 근무 조건 | 근무 시간표 한 줄과 오늘 이후 날짜별 변경 목록 |

## API

| 메서드·경로 | 누가 | 설명 |
|---|---|---|
| `PATCH /api/stores/me/members/{userId}` | 마스터 | `{ hourlyWage?, schedule?: { days, start, end } }` — days 는 0(일)~6(토). 주 시간·일수는 서버가 계산해 저장 |
| `GET /api/stores/me/members/{userId}/schedule-exceptions?from=YYYY-MM-DD` | 마스터 | from 이후 날짜별 변경 |
| `POST /api/stores/me/members/{userId}/schedule-exceptions` | 마스터 | `{ date, kind: "off"\|"work", start?, end? }` — 같은 날짜면 덮어쓴다 |
| `DELETE /api/stores/me/schedule-exceptions/{id}` | 마스터 | 같은 매장만 |
| `GET /api/schedule-exceptions/me?from=YYYY-MM-DD` | 소속 있음 | 내 날짜별 변경 |

멤버·내 소속 응답(`MemberDto`, `MyMembershipDto`)에 `schedule: { days, start, end } | null` 을 더한다.

## 수용 기준

| ID | 기준 |
|---|---|
| WS-1 | 월·수·금 10:00~15:00 저장 → 주 15시간·3일로 저장되고 멤버 응답에 시간표가 온다 |
| WS-2 | 퇴근 ≤ 출근, 요일 0개, 합 52시간 초과 → 400 `VALIDATION_FAILED` |
| WS-3 | 같은 날짜에 두 번 등록하면 하나로 덮어쓴다. `work` 는 시각 필수, `off` 는 시각 없음 |
| WS-4 | 다른 매장 멤버·다른 매장 예외 → 404, 멤버가 마스터 API → 403 |
| WS-5 | 멤버는 내 날짜별 변경만 받는다 |
| WS-6 | 시급 입력칸이 천 단위 쉼표로 보이고(12,000), 저장 값은 숫자다 |
