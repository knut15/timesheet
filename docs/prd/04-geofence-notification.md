# 04. 매장 50m 출근 알림

[← PRD 개요](README.md) · 출근 기록은 [01-attendance.md](01-attendance.md)

## 목표

근무자가 매장 반경 50m 안에 들어오면 "출근 체크하세요" 알림을 띄우고,
**알림을 보낸 지 1분이 지나도 출근 체크가 안 되어 있으면 한 번 더 알린다.**

## 요구사항

| ID | 요구 | 수용 기준 |
|---|---|---|
| G-1 | 매장 위치 지정 | 설정에서 "현재 위치를 매장으로" 를 누르면 그 좌표가 저장된다. 위도·경도를 직접 넣을 수도 있다 |
| G-2 | 위치 감지 | "출근 알림 켜기" 를 누르면 알림 권한과 위치 권한을 요청하고 위치를 계속 받는다 |
| G-3 | 진입 판정 | 현재 위치와 매장 사이 거리(하버사인 공식)가 **50m 이하**면 매장 안으로 본다 |
| G-4 | 첫 알림 | 매장 안이고 출근 기록이 열려 있지 않으면 알림을 한 번 보낸다. 앱 화면에도 출근 버튼이 있는 배너를 띄운다 |
| G-5 | 재알림 | 첫 알림 뒤 **60초**가 지나도 여전히 출근 전이면 재알림을 **한 번** 보낸다 |
| G-6 | 멈춤 | 출근 체크를 하면 알림 주기가 끝난다 |
| G-7 | 재진입 | 50m 밖으로 나갔다 다시 들어오면 G-4 부터 다시 시작한다 |
| G-8 | 상태 표시 | 화면에 매장까지 거리, GPS 정확도, 알림 상태를 보여 준다 |
| G-9 | 알림 클릭 | 알림을 누르면 앱 탭으로 돌아온다 |

## 알림 상태 흐름

```
[밖 또는 출근함] --진입 & 출근 전--> [첫 알림 보냄] --60초 경과 & 출근 전--> [재알림 보냄]
       ^                                  |                                      |
       +------------- 나감 또는 출근 ------+--------------------------------------+
```

이 판정은 `web/src/lib/geo.ts` 의 `nextAlert` 한 함수에 있고 `geo.test.mjs` 로 검증한다.

## 기술 방식

- 위치: 브라우저 Geolocation API `watchPosition` (고정밀 모드)
- 알림: Notification API. 모바일 Chrome 은 `new Notification()` 을 막으므로 서비스 워커(`public/sw.js`)의 `showNotification` 으로 보낸다
- 60초 판정: 앱이 5초마다 상태를 다시 계산한다

## 한계 — MVP 에서 못 하는 것

| 한계 | 이유 | 다음 단계 |
|---|---|---|
| **앱(브라우저 탭)이 열려 있어야** 위치를 받고 알림을 보낸다 | 웹에는 백그라운드 지오펜싱 API 가 없다 | 네이티브 앱(iOS Region Monitoring / Android Geofencing API) 또는 서버 푸시 |
| 화면이 꺼지거나 탭이 백그라운드로 가면 OS 가 위치 갱신·타이머를 늦추거나 멈출 수 있다 | 브라우저 절전 정책 | 위와 같음 |
| iOS Safari 는 홈 화면에 추가한 웹앱에서만 알림을 보낼 수 있다 (iOS 16.4+) | Safari 정책 | 안내 문구로 대응 |
| GPS 오차가 50m 와 비슷할 수 있다 (실내) | 기기 한계 | 정확도 값을 화면에 보여 준다 |
| HTTPS 에서만 동작한다 | 브라우저 보안 정책 | 배포 주소는 HTTPS |
