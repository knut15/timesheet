# 01. 출퇴근 기록

[← PRD 개요](README.md)

## 목표

근무자가 버튼 한 번으로 출근·퇴근 시각을 남기고, 지난 기록을 보고 고칠 수 있다.

## 요구사항

| ID | 요구 | 수용 기준 |
|---|---|---|
| A-1 | 출근 버튼 | 누르면 현재 시각으로 근무 기록이 하나 열린다. 이미 열린 기록이 있으면 출근 버튼이 보이지 않는다 |
| A-2 | 퇴근 버튼 | 열린 기록이 있을 때만 보인다. 누르면 현재 시각으로 그 기록이 닫힌다 |
| A-3 | 진행 중 표시 | 출근 상태에서는 출근 시각과 경과 시간을 보여 준다 |
| A-4 | 기록 목록 | 최근 기록부터 날짜·출근·퇴근·근무시간을 보여 준다 |
| A-5 | 기록 삭제 | 잘못 찍은 기록을 지울 수 있다 |
| A-6 | 기록 수정 | 출근·퇴근 시각을 직접 고칠 수 있다. 퇴근이 출근보다 이르면 저장하지 않는다 |
| A-7 | 보존 | 새로고침·브라우저 재시작 뒤에도 기록이 남는다 (localStorage) |

## 규칙

- 근무 기록은 **출근한 날짜**에 속한다. 자정을 넘겨 퇴근해도 출근일의 근무로 센다.
- 근무시간 = 퇴근 − 출근. MVP 는 휴게시간을 빼지 않는다 ([개요](README.md) 의 제외 항목).
- 한 번에 열린 기록은 하나뿐이다.

## 저장 형식

```ts
type Shift = { id: string; start: number; end: number | null } // epoch ms
```
