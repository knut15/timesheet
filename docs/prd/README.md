# PRD — timesheet

작성일 2026-09-25.

## 무엇을 만드나

파트타임 근무자가 **출퇴근 시간을 기록하고, 그 기록으로 급여를 계산해 보는** 웹 앱이다.
매장 근처에 가면 출근 체크를 잊지 않도록 알림을 보낸다.

## 사용자

| 역할 | 누구 |
|---|---|
| 멤버 | 한 매장에서 시급을 받고 일하는 파트타임 근무자(알바생). 자기 휴대폰 브라우저에서 출퇴근을 찍는다 |
| 마스터 | 매장 주인. 멤버를 초대하고 관리 화면에서 근무·인건비를 본다 (05~07 에서 추가) |

## 1차 MVP 범위 (01~04, 2026-09-25 배포)

| 포함 | 제외 (다음 단계) |
|---|---|
| 근무자 1명, 매장 1곳 | 로그인, 여러 근무자·사업주 화면 → **2차에서 05~07 로 추가** |
| 데이터를 브라우저 localStorage 에 저장 | `server/` (Express + Postgres) 연동 → **2차에서 추가** |
| 앱을 열어 둔 동안의 위치 감지·알림 | 앱을 닫은 상태의 백그라운드 위치 감지 |
| 급여 계산: 기본급·주휴수당·연장근로 가산 | 야간(22~06시)·휴일근로 가산, 휴게시간 차감, 세금·4대보험 공제 |

## 공통 설정값

1차 MVP 에서는 근무자가 직접 넣었고, 06 이후에는 **마스터가 정한다** (멤버는 보기만). 출근 알림 켜기만 기기마다 브라우저에 남는다.

| 설정 | 기본값 | 누가·어디서 | 쓰는 곳 |
|---|---|---|---|
| 시급 | 10,320원 (2026년 최저임금) | 마스터 — 멤버 화면, 멤버별 | 02, 03 |
| 1주 소정근로시간 | 20시간 | 마스터 — 멤버별 | 02, 03 |
| 1주 소정근로일수 | 5일 | 마스터 — 멤버별 | 02, 03 |
| 상시 5인 이상 사업장 | 예 | 마스터 — 매장 화면 | 03 |
| 매장 위치(위도·경도) | 없음 — "현재 위치를 매장으로" | 마스터 — 매장 화면 | 04 |
| 매장 로고 | 없음 | 마스터 — 매장 화면 | 11 |
| 휴가 유급 여부 | — | 마스터 — 승인할 때 | 09 |

"소정근로시간" 은 근로계약서에 적은, 일하기로 약속한 시간이다. 실제로 일한 시간과 다르다.
