# 07. 마스터 관리 화면과 대시보드

[← PRD 개요](README.md) · 권한과 API 는 [06-store-invite.md](06-store-invite.md)

## 목표

마스터가 로그인하면 관리 화면(`/admin`)으로 간다. 여기서 매장 운영에 필요한 것을 한곳에서 본다.
"CMS" 는 이 앱 안의 관리 화면을 말한다 (`~/Workspace/cms` 프로젝트가 아니다).

## 화면

| 경로 | 이 화면에서 끝내야 하는 일 |
|---|---|
| `/admin` | **대시보드.** 지금 누가 일하고 있는지, 이번 달 인건비가 얼마인지 10초 안에 파악한다 |
| `/admin/members` | 멤버 목록. 시급·근무 시간표(요일·출퇴근 시각, 날짜별 변경 — [13](13-work-schedule.md))를 고치고 내보낸다. 주 시간·일수는 시간표로 계산 |
| `/admin/members/[userId]` | 한 멤버의 월별 근무 기록·급여 내역. 기록을 고치고 지운다 |
| `/admin/invites` | 초대 코드 발급·복사·취소, 사용 여부 확인 |
| `/admin/store` | 매장 이름·위치("현재 위치를 매장으로")·5인 이상 여부 |

## 대시보드 구성

| 블록 | 내용 |
|---|---|
| 지금 근무 중 | 출근 중인 멤버 이름·출근 시각·경과 시간. 없으면 "근무 중인 사람이 없어요" |
| 이번 달 인건비 | 전 멤버 예상 급여 합계와 기본급·주휴수당·연장 가산 내역 ([02](02-pay.md) 의 월 합산 규칙) |
| 멤버별 이번 달 | 멤버마다 근무시간, 예상 급여, 이번 주 주휴 상태(개근·진행 중·미충족), 연장근로 |
| 확인 필요 | 주 12시간 넘은 연장근로, 12시간 넘게 퇴근을 안 찍은 기록, 최저임금보다 낮은 시급 |
| 오늘 | 오늘 출근한 멤버 수 / 전체 멤버 수 |

급여 계산은 서버가 아니라 `pay.ts` 한 곳에서 한다 — FE 가 기록과 조건을 받아 계산한다. 계산 로직을 두 벌로 만들지 않는다.

## 대시보드 API

| 메서드·경로 | 내용 |
|---|---|
| `GET /api/stores/me/dashboard?month=2026-09` | 멤버 목록(급여 조건 포함), 그 달에 걸친 주의 기록 전체, 지금 열린 기록 |

## 수용 기준

| ID | 기준 |
|---|---|
| D-1 | 멤버가 출근하면 마스터 대시보드 새로고침 시 "지금 근무 중" 에 나온다 |
| D-2 | 멤버 둘의 월 급여 합이 "이번 달 인건비" 와 같다 |
| D-3 | 멤버 시급을 바꾸면 그 멤버의 예상 급여가 바뀐다 |
| D-4 | 퇴근을 12시간 넘게 안 찍은 기록이 "확인 필요" 에 나온다 |
| D-5 | 멤버 계정으로 `/admin` 에 들어가면 `/` 로 돌려보낸다 |
| D-6 | 좁은 화면(390px)에서 가로 스크롤 없이 보인다 |
