# timesheet 컴포넌트

출퇴근·급여 화면을 만드는 컴포넌트와 규칙. 미리보기는 실제 앱 컴포넌트다.

## 이 가이드를 읽는 법

- 새 화면은 여기 있는 컴포넌트를 조립해서 만든다. 헤더·내비·아바타를 화면마다 새로 그리지 않는다 — <DocLink path=".claude/skills/timesheet-ui/SKILL.md">timesheet-ui 스킬</DocLink> 머리말
- 미리보기는 `web/src/components/` 의 실제 컴포넌트를 그대로 렌더한다. 코드 탭은 그 예시의 원본이다
- 가이드와 코드가 다르면 코드가 맞다

## 기초 토큰

색 토큰 7개. 왼쪽이 라이트, 오른쪽이 다크 값이다.
