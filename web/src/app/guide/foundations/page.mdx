# 기초

## 색 토큰

`@theme inline` 으로 Tailwind 색 이름(`bg-surface`, `text-muted`, `border-line` …)이 된다. 다크는 `prefers-color-scheme: dark` 로만 바뀌고, 가이드에 테마 전환 버튼은 두지 않는다. 다크 견본은 hex 를 직접 칠한 것이다.

## 움직임

- 곡선은 `--ease-out` (`cubic-bezier(0.23, 1, 0.32, 1)`) 하나. `ease-in`·`transition-all` 은 쓰지 않는다.
- 버튼과 하단 내비 링크는 누르는 동안 `scale(0.97)` (120ms). `globals.css` 가 전체에 건다 — 목록 행·카드 링크는 빼서 스크롤 중 출렁이지 않게 한다 — 요소에 `transition-colors` 를 따로 주면 이 전환이 덮인다.
- 오류 문구·저장 완료·온보딩 카드처럼 드물게 보는 것만 `.appear` 로 200ms 등장. 탭 전환처럼 자주 보는 것은 움직이지 않는다.
- 모션 줄이기 설정이면 이동·크기 변화는 끄고 투명도만 남긴다.

## 스크롤 영역·화살표

- 화면 안에서 따로 스크롤되는 곳(코드 블록·넓은 표·긴 목차)은 shadcn **ScrollArea** 를 쓴다 (`@/components/ui/scroll-area`, Base UI·base-nova 원본 그대로). 브라우저 기본 스크롤바를 쓰지 않는다. 이 가이드의 코드 블록·표·목차가 전부 ScrollArea 다.
- 월 이동 같은 좌우 화살표는 lucide `ChevronLeft`/`ChevronRight` 를 `IconButton` 에 태운다. `◀` `▶` 글자를 쓰지 않는다.
- 규칙 원본은 <DocLink path=".claude/skills/timesheet-ui/SKILL.md">timesheet-ui 스킬</DocLink> §0·§2.
