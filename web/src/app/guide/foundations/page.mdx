# 기초

색·글자·간격·모서리·아이콘. 원본은 `web/src/app/globals.css` 와 각 컴포넌트다.

## 색 토큰

`@theme inline` 으로 Tailwind 색 이름(`bg-surface`, `text-muted`, `border-line` …)이 된다. 다크는 `prefers-color-scheme: dark` 로만 바뀌고, 가이드에 테마 전환 버튼은 두지 않는다. 다크 견본은 hex 를 직접 칠한 것이다.

## 타이포

- 글꼴: `body` 의 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. `layout.tsx` 가 Geist 변수를 싣지만 `body` 글꼴 지정이 우선하므로, Geist 는 `font-sans`·`font-mono` 클래스를 준 요소에만 나온다.
- 숫자(금액·시간·날짜)는 `tabular-nums`.
- 굵기: `font-medium`(메뉴·배지) · `font-semibold`(카드 소제목·금액·아바타) · `font-bold`(화면 제목·총액·오늘 숫자).
