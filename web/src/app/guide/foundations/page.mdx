# 기초

색·글자·간격·모서리·움직임·아이콘·일러스트·스크롤. 기준의 원본은 루트 `DESIGN.md`, 코드는 `web/src/app/globals.css` 와 각 컴포넌트다.

## 색 토큰

`@theme inline` 으로 Tailwind 색 이름(`bg-surface`, `text-muted`, `border-line` …)이 된다. 앱은 기기 설정과 상관없이 항상 라이트다(2026-10-15). 다크 값은 `.dark` 클래스 블록에만 남아 있고 지금은 쓰지 않으며, 가이드에 테마 전환 버튼은 두지 않는다. 다크 견본은 hex 를 직접 칠한 것이다.

중립색 다섯(바탕·글자·카드·선·보조 글자)은 2026-10-15 사용자 결정 "컬러도 바꿔줘 시안처럼" 으로 청록 기운 없는 회색이 됐다. 강조색·상태색은 그대로다. 대비 값은 루트 `DESIGN.md` §2 표에 있다 — 예를 들어 보조 글자는 바탕 위 5.05(라이트) / 7.76(다크).

## 타이포

- 글꼴: 본문은 **Pretendard**(가변, `next/font/local` 로 앱이 직접 제공 — `layout.tsx` 의 `--font-pretendard`, `font-sans` 도 같은 글꼴). 없을 때만 `system-ui` 계열로 떨어진다. 코드는 `font-mono` = Geist Mono.
- 숫자(시각·시간·금액·날짜)는 고정폭 글꼴로 쓴다. `ui.tsx` 의 `NUM` 상수(`font-mono tabular-nums`)를 붙이면 된다 — 자릿수가 바뀌어도 글자 폭이 같아 숫자가 흔들리지 않는다. 시계·큰 급여 숫자는 여기에 강조색(`text-accent`)을 더한다.

```tsx
import { NUM } from "@/components/ui";
<p className={`text-3xl font-bold ${NUM}`}>{won(total)}</p>
```

- 굵기: `font-medium`(메뉴) · `font-semibold`(배지·구역 머리·금액·시계·큰 급여 숫자·아바타) · `font-bold`(화면 이름·오늘·선택한 날 숫자).

## 움직임

움직임은 두 가지로 나뉜다. 매번 손에 닿는 누름 반응은 CSS 가 맡고, 화면이 바뀌거나 무언가 끝나는 순간은 GSAP(3.15) 모션이 맡는다(2026-10-15 사용자 결정). 기준의 원본은 루트 `DESIGN.md` 다.

### GSAP 모션 4종

코드는 `web/src/components/motion.tsx`. 쓰는 법과 예시는 [Motion 페이지](/guide/components/motion).

- 곡선은 GSAP `power2.out`(`motion.tsx` 의 `EASE`). CSS 의 `--ease-out` 과 같은 성격 — 빠르게 출발해 천천히 멈춘다.
- 모션 줄이기 설정(`prefers-reduced-motion`)이면 4종 모두 이동 없이 투명도만 바꾼다. `CountUp` 은 숫자를 바로 보인다.
- 탭 전환처럼 하루 수십 번 보는 것에는 걸지 않는다.

### CSS 누름·등장

- 곡선은 `--ease-out` (`cubic-bezier(0.23, 1, 0.32, 1)`) 하나. `ease-in`·`transition-all` 은 쓰지 않는다.
- 버튼과 하단 주요 메뉴는 누르는 동안 `scale(0.97)` (120ms `--ease-out`), 색 변화는 150ms `ease`. `globals.css` 가 전체에 건다 — 목록 행·카드·목차 링크는 빼서 스크롤 중 출렁이지 않게 한다. 누름 대상에 Tailwind `transition` 을 따로 주면 이 규칙이 덮인다.
- 레이아웃 속성(`left`·`width` …)은 전환하지 않는다 — 토글 손잡이도 `translate-x` 로 움직인다.
- 오류 문구(`ErrorText`)·온보딩 카드는 `.appear` 로 200ms 등장(위로 4px), 여러 개면 50ms 간격.
- 모션 줄이기 설정이면 누름 축소는 끄고 `.appear` 는 투명도만 남긴다.

## 일러스트

빈 화면·로그인·온보딩처럼 잠깐 머무는 자리에는 lucide 아이콘을 엮은 작은 장면을 둔다(2026-10-15 사용자 결정). 그림 파일을 따로 들이지 않고, **사람 그림은 쓰지 않는다** — 뜻은 사물로 보여 준다(예: 출퇴근 = 시계 + 커피 잔 + 해).

- 가운데 옅은 강조색 원(`bg-accent/10`, 테두리 `border-accent/20`)에 주인공 아이콘 하나(강조색), 둘레 네 모서리 중 1~2곳에 작은 소품(`text-muted`). 선 굵기 1.5.
- 크기는 두 가지: `md` 원 64px·주인공 30px·소품 16px, `sm` 원 44px·주인공 22px·소품 13px.
- 처음 그릴 때 원이 살짝 올라오고 소품이 0.08초 간격으로 튀어나온다. 장식이라 `aria-hidden`.
- 한 화면에 하나만 둔다. 작은 구역의 빈 상태는 장면 없이 글자만 쓴다.

코드는 `web/src/components/illust.tsx`, 예시는 [Scene 페이지](/guide/components/scene).

## 스크롤 영역·화살표

- 화면 안에서 따로 스크롤되는 곳(코드 블록·넓은 표·긴 목차)은 shadcn **ScrollArea** 를 쓴다 (`@/components/ui/scroll-area`, Base UI·base-nova 원본 그대로). 브라우저 기본 스크롤바를 쓰지 않는다. 이 가이드의 코드 블록·표·목차가 전부 ScrollArea 다.
- 월 이동 같은 좌우 화살표는 lucide `ChevronLeft`/`ChevronRight` 를 `IconButton` 에 태운다. `◀` `▶` 글자를 쓰지 않는다.
- 규칙 원본은 <DocLink path=".claude/skills/timesheet-ui/SKILL.md">timesheet-ui 스킬</DocLink> §0·§2.
