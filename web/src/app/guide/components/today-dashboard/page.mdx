# Today Dashboard

멤버 출퇴근 탭의 오늘 근무 카드. 오늘 → 처리할 것 → 이번 주 → 이번 달 네 구역이다. 숫자는 전부 `lib/pay.ts` 가 계산하고 이 컴포넌트는 보여주기만 한다. 급여 탭과 같은 데이터면 같은 값이 나온다.

## 사용법

```tsx
const minuteNow = toMinute(useNow(1_000));

<TodayDashboard
  shifts={shifts}
  absences={absences}
  requests={requests}
  settings={settings}
  now={minuteNow}
  status="ready"
  onRetry={reload}
  onOpenPay={openPay}
  onOpenRequests={openRequests}
/>
```

## 구성

```
TodayDashboard  Card p-0 divide-y divide-line
├─ ① 오늘  <section px-5 py-4>
│  ├─ h2 "오늘" + 합계 hm()
│  └─ <ul> 오늘 출근한 기록 × 행  time(start) ~ time(end) | OpenDot 근무 중 + hm()
│     (없으면 "아직 오늘 기록이 없어요." / 쉬는 날이면 "오늘은 쉬는 날이에요.")
├─ ② 처리할 것  <section>  (0건이면 구역째 없음)
│  └─ TodoRow (내부) <button min-h-11> 받은 대타 요청 · 내 대기 요청 + N건 + ChevronRight
├─ ③ 이번 주  <section px-5 py-4>
│  ├─ h2 "이번 주" + 기간 text-xs
│  └─ <dl> 근무 시간 · ProgressBar · 근무한 날 · 주휴수당 holidayStatus()
└─ ④ 이번 달  <button min-h-11>  "{월}월 예상 급여 (세전)" + won() + "급여 탭에서 자세히"
```

`status` 가 `"loading"`·`"error"` 면 구역 없이 한 줄 또는 오류 + `다시 불러오기` 만 그린다.

예시는 모두 2026년 9월 25일(금), `now` 에는 `minuteNow`(14:32)를 넘긴다. 기록은 아래 파일 하나를 Clock Card 예시와 같이 쓴다. 기본 absence 는 9월 24일 대타.

## 처리할 것

받은 대타 요청 2건(`이서준`·`박도윤`, 수락 전) · 내 대기 요청 1건(휴가 승인 대기). 행을 누르면 `onOpenRequests`.

<ComponentPreview name="today-dashboard/todo" width="max-w-md" />

## 가입 첫날

기록·휴가 0. 구역은 그대로 두고 값만 0 — 오늘 `0시간`, 이번 주 `0시간 / 20시간`, 주휴 `진행 중 (0/5일)`, 이번 달 `0원`.

<ComponentPreview name="today-dashboard/first-day" width="max-w-md" />

## 오늘 휴가

오늘 기록을 빼고 9월 25일 유급 휴가를 더했다 → 오늘 목록 대신 `오늘은 쉬는 날이에요.`

## 소정 초과

`s4` 를 18:00 퇴근으로, 토요일 9/26 09:00~17:00 을 더하고 기준 시각을 9/26 18:00 으로. 막대는 가득 차고 글자는 실제 값 `25시간 28분 / 20시간`, 주휴 `개근`. 연장·한도 경고는 급여 탭에만 있다.

## 주 15시간 미만

Basic 에서 소정 주 14시간 → 주휴 `대상 아님 (주 15시간 미만)`.

## 불러오는 중

구역 없이 한 줄 `불러오는 중…`. `Spinner`(py-20)는 첫 화면에서 너무 높아 쓰지 않는다.

<ComponentPreview name="today-dashboard/loading" width="max-w-md" />

## 불러오기 실패

기록이나 휴가 중 하나라도 못 읽으면 실패다. 오류 글자와 `다시 불러오기`(`onRetry`).

## 하지 말 것

- `now` 에 1초 단위 시각을 넘기지 않는다 — `minuteNow` 를 넘긴다. 시계 카드의 경과와 1분 어긋난다.
- 주휴 글자를 새로 만들지 않는다 — `holidayStatus` 가 급여 탭 주별 카드와 같은 글자를 낸다.
- 예시에서 금액·시간을 손으로 적어 넣지 않는다.
- 이 카드를 시계 카드 안에 넣지 않는다 — 카드 안에 카드를 두지 않는다.
