# Dialog

화면 위에 뜨는 모달. 사장 화면 멤버 카드의 "조건 수정" 과 멤버 기록 탭의 추가·수정·삭제 요청이 쓴다. [shadcn Dialog](https://ui.shadcn.com/docs/components/base/dialog)(base-nova) 원본을 그대로 두고 바깥 `className` 으로 맞춘다.

## 사용법

```tsx
const [open, setOpen] = useState(false);

<Dialog open={open} onOpenChange={setOpen}>
  <DialogContent className="bg-surface p-5 sm:max-w-md">
    <DialogHeader>
      <DialogTitle className="text-lg font-semibold">이서준 조건 수정</DialogTitle>
    </DialogHeader>
    {/* 입력칸 */}
    <DialogFooter className="-mx-5 -mb-5 flex-row border-line bg-transparent px-5 py-4">
      <button className={`${BTN.secondary} flex-1`}>취소</button>
      <button className={`${BTN.primary} flex-1`}>저장</button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## 기록 수정 요청 모달

멤버 기록 탭에서 빠진 기록 추가·수정·삭제 요청을 보낼 때 뜨는 모달이다 (2026-10-15 사용자 요청 "빠진기록 요청은 모달팝업으로", "수정 요청도 마찬가지야", "삭제도 마찬가지로"). 진짜는 `web/src/components/member/RecordsPanel.tsx` 의 `RequestDialog`(내부, export 안 됨)이고, 아래 예시는 같은 틀에 보내기만 뺀 것이다.

- 제목(`DialogTitle`, 18px 굵게)과 설명(`DialogDescription`, 13px muted)이 모달 머리다. 폼에는 제목을 따로 두지 않는다.

## 우리 쪽 맞춤 — 원본은 고치지 않는다

    ["긴 내용", "`max-h-[calc(100dvh-2rem)] overflow-y-auto`", "좁은 휴대폰 화면에서 저장 버튼까지 스크롤"],
    ["움직임", "`tw-animate-css` (흐림·확대)", "원본 animate-in 클래스가 이 패키지 것이다"],
  ]}
/>

푸터 버튼은 [Button](/guide/components/button) 의 `BTN` 이다 — 취소 `BTN.secondary`, 저장 `BTN.primary`, 둘 다 `flex-1` 로 나란히. 옛 이름 `ACT_CANCEL`·`ACT_SAVE` 도 같은 값이다.

닫기(X) 버튼은 원본이 `ui/button.tsx`(shadcn Button, class-variance-authority)로 그린다. 앱 코드에서는 Button 을 직접 쓰지 않는다.

## 접근성

- 제목은 `DialogTitle` — 모달 이름으로 읽힌다. 빼지 않는다.
- 열리면 초점이 모달 안으로 들어가고, Esc·바깥 누름·X 로 닫힌다(base-ui).
