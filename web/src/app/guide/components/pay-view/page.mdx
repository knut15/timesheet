# Pay View

월 급여 요약 카드와 주별 내역 카드. 큰 급여 숫자는 강조색이고, 바뀔 때 숫자가 올라가며 바뀐다. 멤버 급여 탭과 마스터 멤버 상세가 같이 쓴다. 계산은 `lib/pay.ts` 가 하고 이 컴포넌트는 보여주기만 한다. 아래 금액은 모두 미리보기가 `pay.ts` 로 계산한 값이다.

## 사용법

```tsx
<PayView shifts={shifts} settings={settings} year={2026} month={8} now={now} />
```

## 구성

```
PayView  <Enter space-y-3 replay={replay}>   카드가 차례로 나타난다
├─ 요약 Card
│  ├─ SectionLabel PiggyBank "예상 급여 (세전)"
│  ├─ 총액 <p text-[30px] font-semibold text-accent NUM> <CountUp value={total} format={won} />
│  ├─ <dl text-[13px]> DotRow × 기본급(시간) · 주휴수당 · 휴가수당(있을 때만) · 연장 가산(시간)
│  │     금액이 0원인 줄은 muted
│  └─ 안내 글자 text-xs (합산 기준·미반영 항목)
├─ 빈 달 글자 "이 달 기록이 없어요." (주가 0개일 때)
└─ WeekCard (내부) × 주
   ├─ SectionLabel CalendarDays "10/13 (월) ~ 10/19 (일)" 오른쪽 = 주 합계
   ├─ <dl> DotRow × 근무 · 기본급 · 휴가수당(있을 때) · 주휴수당 · holidayStatus · 연장(5인 미만 표시)
   │     주휴 상태 글자: 개근 text-ok, 진행 중 text-caution
   └─ 한도 경고 text-warn (연장 12시간 초과)
```

예시는 모두 2026년 9월, 기준 시각 `now` 는 9월 30일 18:00 으로 고정한다. 시급은 `lib/pay.ts` 의 `MINIMUM_WAGE`(2026) 와 같은 10,320원이다.

## 점선 이음 줄 — DotRow

`이름 ··········· 값` 한 줄. `PayView` 안의 내역이 쓰고, 다른 화면에서도 같은 모양으로 쓰도록 내보낸다. `<dl className="mt-2.5 grid gap-1.5 text-[13px]">` 안에 쌓는다. 점선은 줄의 `::after` 로 그려 `dt`·`dd` 구조를 해치지 않는다.

## 사용 규칙

계산식은 <DocLink path="docs/prd/02-pay.md">PRD 02</DocLink>·<DocLink path="docs/prd/03-overtime.md">PRD 03</DocLink>, 휴가는 <DocLink path="docs/prd/09-leave-substitution.md">PRD 09</DocLink>. 프로젝트 규칙 "화면 컴포넌트에서 금액을 계산하지 않는다"(`CLAUDE.md` §2).

## 하지 말 것

- 예시에서 금액을 손으로 적어 넣지 않는다.
- `now` 를 `Date.now()` 로 두지 않는다.
- `WeekCard` 를 따로 쓰려 하지 않는다 — export 되지 않는다.

### holidayStatus(week, settings, now): string

주휴 상태 글자. 결과는 아래 중 하나다.

- `대상 아님 (주 15시간 미만)`
- `개근`
- `대상 아님 (그 주 전부 휴가)`
- `진행 중 (n/m일)`
- `미충족 (n/m일)`
