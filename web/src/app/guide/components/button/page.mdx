# Button

앱의 버튼 모양. shadcn [Button](https://ui.shadcn.com/docs/components/base/button) 의 `buttonVariants` 위에 크기만 얹은 클래스 묶음이다. 색 테두리(파랑·빨강)는 쓰지 않는다 — 2026-09-25 "버튼 디자인이 너무 촌스럽다, 모던하게".

- 주 색(`primary`)은 `globals.css` 에서 `foreground` 로 잇는다 — 라이트 검정, 다크 흰색.
- 같은 줄에 주 동작은 하나만 검정으로 둔다.
- 예외: 멤버 출퇴근 카드의 출근·퇴근 큰 버튼과 매장 50m 배너는 상태를 색으로도 구별해서 명세([오늘 근무](/guide/components/clock-card))의 색을 그대로 쓴다.
