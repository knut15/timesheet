# Button

버튼 모양 상수 `BTN`. 컴포넌트가 아니라 클래스 묶음이라 `<button>`·`<a>` 에 그대로 붙인다. 색 테두리(파랑·빨강) 없이 주 동작은 진한 바탕, 보통 동작은 가는 선, 추가는 점선으로 나눈다.

<ComponentPreview name="button/variants" />

<FileLocation path="web/src/components/styles.ts" importLine={`import { BTN } from "@/components/ui";`} />

`BTN` 은 `styles.ts` 에 있고 `ui.tsx` 가 다시 내보낸다. 가져올 때는 `@/components/ui` 를 쓴다.

## 사용법

```tsx
<button className={BTN.primary}>출근하기</button>
<button className={`${BTN.secondary} w-full`}>매장 만들기</button>
```

## 구성

다섯 모양 모두 `inline-flex items-center justify-center rounded-xl`(6px) 이 바탕이다.

## 사용 규칙

누름 반응과 색 전환은 `globals.css` 가 모든 버튼에 건다 — 기초 페이지 "움직임" 절.

예외: 멤버 출퇴근 카드의 출근·퇴근 큰 버튼과 매장 50m 배너는 상태를 색으로도 구별하므로 명세([Clock Card](/guide/components/clock-card))의 색을 그대로 쓴다.

## 하지 말 것

- 버튼마다 `rounded-*`·`h-*`·색을 새로 쓰지 않는다. 모양이 더 필요하면 `BTN` 에 추가를 요청한다.
- 버튼에 Tailwind `transition`·`transition-colors` 를 붙이지 않는다 — `globals.css` 의 누름 전환이 덮인다(테스트가 막는다).
- 한 화면에 `BTN.primary` 를 여러 개 두지 않는다. 주 동작은 하나다.
- 아이콘만 있는 버튼은 `BTN` 대신 `IconButton` 을 쓴다.
- 새 코드에 옛 이름을 쓰지 않는다.
