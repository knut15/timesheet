# Clock Card

멤버 출퇴근 탭의 시계 카드. 날짜, 한 줄 시계, 지금 상태, 출근·퇴근 버튼을 한 카드에 둔다. API 를 부르지 않는 표시 컴포넌트라 상태는 부르는 쪽이 `todayState` 로 정해 넘긴다.

## 사용법

```tsx
const now = useNow(1_000);
const minuteNow = toMinute(now);
const state: ClockState = loading ? { kind: "loading" } : failed ? { kind: "error" } : todayState(shifts, absences, minuteNow);

<ClockCard now={now} minuteNow={minuteNow} state={state} busy={busy} error={error} onPunch={punch} onRetry={reload} />
```

`todayState`·`toMinute` 는 `@/lib/today`, `useNow` 는 `@/components/ui`.

## 근무 중

초록 점 + `퇴근`. 설명의 출근 시각은 오늘 첫 출근이 아니라 **지금 열린 기록**(`s4`)의 출근 시각이다.

<ComponentPreview name="clock-card/working" width="max-w-md" />

## 근무 중 — 어제 출근

어제 22:00 에 출근해 퇴근하지 않은 기록. 설명에 날짜가 붙는다 — `9. 24. 오후 10:00 출근 · 지금까지 16시간 32분`.

<ComponentPreview name="clock-card/working-yesterday" width="max-w-md" />

## 오늘 퇴근함

오늘 기록 중 가장 늦은 퇴근 시각. 다시 출근은 없다 — 내일 0시까지 버튼이 비활성이다.

<ComponentPreview name="clock-card/done" width="max-w-md" />

## 오늘 휴가

점선 알약과 유급 문구. 휴가 날에도 출근은 막지 않아 버튼을 보조 모양으로 낮추고 아래에 안내 한 줄.

## 하지 말 것

- 경과 시간을 `now`(1초)로 계산하지 않는다 — `minuteNow` 를 넘긴다. 대시보드 오늘 합계와 1분 어긋난다.
- 시계 글자에 `aria-live` 를 걸지 않는다.
- 상태 알약에 색 바탕(`bg-green-500/15` 등)을 쓰지 않는다 — 작은 글자 대비 4.5 미달(명세 §8).
- 예시에서 `now` 를 `Date.now()` 로 두지 않는다.

`todayState(shifts, absences, now): TodayState` — 판정 순서는 열린 기록 → 오늘 기록 → 오늘 absence → 출근 전. `toMinute(t)` — 분 단위로 자른 시각.
