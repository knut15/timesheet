# Icon Button

아이콘만 있는 버튼. 헤더에는 테두리 없는 `ghost`, 월 이동처럼 본문 안에는 테두리 있는 `outline` 을 쓴다. 이름은 `aria-label` 과 `title` 로 붙는다.

<ComponentPreview name="icon-button/basic" />

<FileLocation path="web/src/components/shell.tsx" importLine={`import { IconButton } from "@/components/shell";`} />

## 사용법

```tsx
<IconButton icon={LogOut} label="로그아웃" onClick={() => logout()} />
```

## 구성

```
IconButton  <button type="button" aria-label={label} title={label}, 44×44 rounded-xl(6px)>
│  ghost   text-muted, 마우스를 올리면 bg-line/60
│  outline border border-line bg-surface text-foreground, 마우스를 올리면 bg-background
└─ Icon aria-hidden — ghost 20px / outline 18px
```

## 헤더 안

`AppHeader` 의 `actions` 자리. App Header 의 "마스터 + 로그아웃" 과 같은 데이터다.

<ComponentPreview name="icon-button/in-header" fixed />

## Outline

`variant="outline"`. 본문 안에서 버튼 자리가 보여야 할 때 쓴다 — `MonthPicker` 의 이전·다음 달 화살표가 이 모양이다.

- 아이콘 버튼을 `button` 안에 아이콘만 넣어 직접 만들지 않는다.
- `label` 을 비우지 않는다.
