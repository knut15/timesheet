# App Header

모든 화면의 머리. 위 작은 줄(매장·역할)과 화면 제목, 오른쪽에 동작과 내 아바타.

<FileLocation path="web/src/components/shell.tsx" importLine={`import { AppHeader } from "@/components/shell";`} />

## 사용법

```tsx
<AppHeader eyebrow="데모 카페 성수점" title="출퇴근" me={{ id: "user-demo-01", nickname: "김하늘" }} width="max-w-md" />
```

## 구성

```
AppHeader  <header sticky top-0, border-b, bg-background/90 blur>
└─ 폭 틀  <div mx-auto {width} px-5 py-3>
   ├─ 글자 묶음
   │  ├─ eyebrow 줄  <p text-xs text-muted>
   │  │  ├─ 로고 <img alt={logoAlt} h-5 max-w-24> (logoUrl 있을 때 — 매장 이름 글자를 대신)
   │  │  └─ eyebrow  <span 한 줄 자름>
   │  └─ title    <h1 text-xl font-bold, 한 줄 자름>
   └─ 오른쪽 묶음
      ├─ actions  (넘긴 그대로)
      └─ Avatar md, label "<nickname> (나)"
```

## 마스터 + 로그아웃

`actions` 자리에 `IconButton` 을 둔다. 폭은 기본값(`max-w-3xl`).

## 로고

매장 로고가 있으면 `logoUrl` 로 넘긴다. eyebrow 줄 맨 앞에 높이 20px, 가로 최대 96px 로 비율을 지켜 놓인다. **로고가 매장 이름 글자를 대신한다** — eyebrow 에서 매장 이름을 빼고(멤버는 빈 값, 마스터는 `"사장님"`), 이름은 `logoAlt` 로 넘겨 스크린리더가 읽게 한다. 규칙은 <DocLink path="docs/prd/11-store-logo.md">PRD 11</DocLink>.

<ComponentPreview name="app-header/logo" width="max-w-md" fixed />

## 하위 화면 — 브레드크럼과 서브헤더

탭 안의 하위 화면(멤버 › 근무 기록, 멤버 › 초대 코드)은 `crumbs` 로 상위 화면 링크를 제목 앞에 붙이고, 헤더 바로 아래 `SubHeader` 로 뒤로 가기를 둔다. 서브헤더는 헤더와 같은 폭의 띠(`bg-surface` + 아래 선)라 본문과 확실히 나뉜다 (2026-09-25 사용자 요청).

## 하지 말 것

- 화면마다 `header` 를 새로 만들지 않는다.
- `me.id` 에 이름을 넣지 않는다 — 아바타 색이 화면마다 달라진다.
- `width` 를 본문 폭과 다르게 주지 않는다.
