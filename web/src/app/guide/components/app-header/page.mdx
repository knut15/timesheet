# App Header

모든 화면의 머리. 한 줄에 `매장 / 화면 이름` 을 두고 화면 이름을 굵게 강조한다. 오른쪽에 동작과 내 아바타.

<FileLocation path="web/src/components/shell.tsx" importLine={`import { AppHeader } from "@/components/shell";`} />

## 사용법

```tsx
<AppHeader eyebrow="데모 카페 성수점" title="출퇴근" me={{ id: "user-demo-01", nickname: "김하늘" }} width="max-w-md" />
```

## 구성

```
AppHeader  <header sticky top-0, border-b, bg-surface/95 blur>
└─ 폭 틀  <div mx-auto {width} h-16 px-5>
   ├─ 한 줄 묶음  <div flex h-7 items-center gap-1.5>
   │  ├─ 로고 <img alt={logoAlt} h-5 max-w-24> (logoUrl 있을 때 — 매장 이름 글자를 대신)
   │  ├─ eyebrow  <span text-[15px] font-medium text-muted, 한 줄 자름> (값이 있을 때)
   │  ├─ 나눔 "/"  <span aria-hidden text-muted/50> (로고나 eyebrow 가 있을 때)
   │  ├─ title    <h1 text-lg(18px) font-bold, 줄어들지 않음> (crumbs 가 없을 때)
   │  └─ 브레드크럼  <nav aria-label="현재 위치"><ol> (crumbs 가 있을 때)
   │     ├─ 상위 화면 <Link text-[15px] font-medium text-muted> + ChevronRight 15px × crumbs
   │     └─ title  <h1 aria-current="page" text-lg font-bold, 한 줄 자름>
   └─ 오른쪽 묶음  <div gap-1>
      ├─ actions  (넘긴 그대로)
      └─ Avatar sm(32px), label "<nickname> (나)"
```

## 로고

매장 로고가 있으면 `logoUrl` 로 넘긴다. 한 줄 맨 앞, 매장 이름 자리에 높이 20px, 가로 최대 96px 로 비율을 지켜 놓인다. **로고가 매장 이름 글자를 대신한다** — eyebrow 에서 매장 이름을 빼고(멤버는 빈 값, 마스터는 `"사장님"`), 이름은 `logoAlt` 로 넘겨 스크린리더가 읽게 한다. 규칙은 <DocLink path="docs/prd/11-store-logo.md">PRD 11</DocLink>.

<ComponentPreview name="app-header/logo" width="max-w-md" fixed />

## 하위 화면 — 브레드크럼과 서브헤더

탭 안의 하위 화면(멤버 › 근무 기록, 멤버 › 초대 코드)은 `crumbs` 로 상위 화면 링크를 같은 한 줄의 제목 앞에 붙인다 — `데모 카페 성수점 / 멤버 › 근무 기록`. 상위 화면은 15px 회색 링크, 마지막 화면 이름만 18px 굵게다. 한 줄 묶음은 `h-7` 고정이라 헤더 높이(64px)는 그대로다. 뒤로 가기는 헤더 바로 아래 `SubHeader` 에 둔다. 서브헤더는 헤더와 같은 폭의 띠(`bg-surface` + 아래 선)라 본문과 확실히 나뉜다 (2026-09-25 사용자 요청).

## 하지 말 것

- 화면마다 `header` 를 새로 만들지 않는다.
- `me.id` 에 이름을 넣지 않는다 — 아바타 색이 화면마다 달라진다.
- `width` 를 본문 폭과 다르게 주지 않는다.
