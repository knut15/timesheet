## 하지 말 것

- 화면마다 로딩 글자를 새로 쓰지 않는다. 단, 달력 격자 안처럼 좁은 자리는 `footer` 에 `불러오는 중…` 한 줄을 직접 둔다 — Month Grid 의 "불러오는 중" 예시.
